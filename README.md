# ドーシャ割合チェック

ヴァータ、ピッタ、カパの点数から構成割合と最大タイプを表示する、依存関係なしの最小Webプロトタイプです。医療診断ではなく、一般的なウェルネス情報として提供します。

## 使い方

`index.html` をブラウザで開いてください。外部通信やビルドは不要です。

3項目に0以上の整数を入力し、「割合を確認する」を押すと、点数・割合・最大タイプ・商品推薦欄が表示されます。同点の場合は複合タイプになります。

## 商品情報の設定

`config.js` の `recommendations` に、対象タイプごとの `name` と任意の `description` を設定できます。未設定の場合は準備中メッセージを表示します。

```js
vata: {
  name: "提供された商品名",
  description: "提供された商品説明"
}
```

複合タイプ用のキーは `compound` です。商品名・説明は、実際に提供された情報だけを設定してください。

## テスト

Node.jsがすでにインストールされている場合、追加パッケージなしで次を実行できます。

```text
node tests/calculator.test.js
```
